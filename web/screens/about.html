About BlackHole Arena

BlackHole is played by two players on a graph of 2N + 1 nodes. Each player has N turns: on your n-th turn you place n tiles on a free node. After the 2N turns exactly one node is still free — that node is the black hole.

Each player scores the tiles it placed on the nodes next to the black hole. Everything else is lost.

Not a zero-sum game

Each player tries to maximize its own score. Both players can score well in the same game, or both badly. That is why the tournament ranks players by the points they collect over all their games, not by how many games they "won".

X-ray mode

Turn on X-ray during a game to see, under every free node, what each player would score if that node became the black hole right now. Remember that the biggest moves come last: a player's final turn places N tiles at once.

One source of truth

The game rules and every AI are written once, in Python. This page loads that exact code through Pyodide (Python compiled to WebAssembly) — the rules are never re-implemented in JavaScript. The same code also runs the automated tournament in GitHub Actions.
